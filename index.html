CONNECT THE PULL BUTTON

The button starts a job on GitHub that scans your 38 company boards and adds new matches here. It needs two things, once:

  1. A secret on the repo. In Settings → Secrets → Actions, add TRACKER_PASSPHRASE with this page's passphrase as the value.
  2. A token for this device. Create a fine-grained token: repository access Only select repositories → job-tracker; permissions Actions: Read and write and Contents: Read-only. Paste it below.

The token stays in this browser only and can do nothing outside job-tracker. Remove it any time with Disconnect.
